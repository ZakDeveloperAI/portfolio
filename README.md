# Zakaria Belfakhir — Personal Site

Personal site for Zakaria Belfakhir, Founding AI Engineer at LIV4.AI. Built with Next.js (App Router), TypeScript, Tailwind CSS and Framer Motion.

## Stack

- Next.js 13 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion

## Development

```bash
npm install
npm run dev
```

## Content

All copy lives in [lib/data.ts](lib/data.ts). Update it there rather than in the components.
